## 五、维护约定

1. 每条结论必须能指到依据：一次响应片段、一条命令、或 `tests/fixtures/` 里的样本。
2. 结论变了就改这一行，不追加"补充说明"——保持每次读到的是当前事实。
3. 能力级细节（单位、层级、前置条件）不写这里，写进 `baidu/descriptions.json` 的
   `notes` / `params`，让 agent 在 schema 里直接看到。
